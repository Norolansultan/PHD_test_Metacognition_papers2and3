# Studies

Two collections, four papers. No statistical inference is made between papers: different
participants, different regimes, different measurement density. The synthesis chapter compares them
theoretically, which is normal in an article dissertation.

| Paper | Collection | Participants | Manipulation |
|---|---|---|---|
| 1 | [Study I](study-i-army.md), phase 1 | army, ~100 | Human-mediated vs AI-mediated situation picture |
| B | [Study I](study-i-army.md), phase 2 | same | Who interprets the vague order |
| A | [Study II](study-ii-rescue.md) | rescue (recommended) | Social information as opinion vs as model input |
| D | none of its own | — | Proxy validation against the offline gold standard |

Both studies use the same engine, the same logging schema, and the same measurement apparatus. They
differ in content package and in which manipulation is active.

Every participant in every study first completes the
[200-item calibration battery](../measurement/calibration-battery.md).
